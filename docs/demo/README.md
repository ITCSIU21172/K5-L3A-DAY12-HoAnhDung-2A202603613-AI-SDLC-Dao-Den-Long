# Video Demo Hướng Dẫn

Học viên quay video màn hình `.mp4` dưới 5 phút thể hiện:
1. Trải nghiệm chơi trực tiếp game 3D Đảo Đèn Lồng trên trình duyệt (`npm start`).
2. Chạy bộ kiểm thử tự động `npm test` chứng minh toàn bộ 24 test assertions đạt kết quả tốt.
3. Chạy lệnh headless CLI theo Test Contract v1.0 và kiểm tra output JSONL.
4. Lướt qua lịch sử commit git, các tag và file harness `AGENTS.md`.

Lưu video tại `docs/demo/demo.mp4` (dưới 100MB) hoặc đính kèm vào GitHub Release `v1.0.0`.
